# Juan Paolo Dente, Portfolio

This is the code for my portfolio site: https://nitroatomic.github.io

It is a plain HTML, CSS and JavaScript site with no build step. GitHub Pages serves it straight from this repo.

## What is in here

- `index.html` is the whole site
- `404.html` is the page people see when a link is wrong
- `assets/` has the styles, scripts, screenshots and the project PDFs
- `assets/style.css` and `assets/main.js` are the files to edit. The site loads `style.min.css` and `main.min.js`, so copy any change into those too
